## 🌟 الميزات التقنية للبورتفوليو

1. **تصميم متكامل مع GitHub Pages**: مبني بتقنيات الويب النقية (HTML5, Modern CSS3, Vanilla JS) بدون الحاجة إلى أي أدوات بناء (Build Tools) أو Node.js — يعمل فور رفعه على GitHub مباشرة.
2. **استخراج الصورة الشخصية بجودة فائقة**: استخراج صورتك الأصلية من ملف الـ PDF واستخدامها مع تأثير **3D Tilt** التفاعلي عند تحريك الفأرة.
3. **كانفاس تدفق البيانات النيوني (Neon Data Stream Canvas)**: خلفية تفاعلية متحركة خلف صورتك الشخصية تعرض رموز وهيكليات هندسة البيانات (`ETL`, `SQL`, `DF`, `0xFF`, `3NF`, `ROW`).
4. **شريط مسار تدفق البيانات التفاعلي (Data Pipeline Architecture)**: محاكي لرحلة البيانات من المصادر الأولية (IoT/ESP32, CSVs) ➔ معالجة بايثون (Pandas/ETL) ➔ مستودع SQL Server ➔ تحليلات وتقارير الأعمال (KPIs)، مع إمكانية النقر على أي مرحلة لفحص تفاصيلها.
5. **تيرمينال استعلامات تفاعلي (Interactive SQL & Python Console)**: محاكي تيرمينال مباشر يمكن لزوار الموقع ومسؤولي التوظيف تشغيل استعلامات SQL حية وفحص النتائج ومعدلات الأداء.
6. **عدادات مقاييس حية (Telemetry Stats)**: عدادات أرقام تفاعلية تتحرك تلقائياً عند التمرير لتسليط الضوء على إنجازاتك (`10,000+` Rows, `25%` Query Optimization, `100%` DEPI Accuracy, `1,000+` Sensor Readings).
7. **مصفوفة المهارات الذكية (Skills Matrix with Filters)**: تصفية المهارات حسب التصنيف (Programming & DB, Data Engineering, Processing & Analytics, AI & Hardware).
8. **عرض المشاريع المختارة (Selected Projects)**: عرض المشاريع الأربعة مع البنية التقنية وبطاقات الأدوات وروابط المستودعات.
9. **سيرة ذاتية مدمجة للتنزيل الفوري (DOWNLOAD CV)**: زر مباشر في أعلى الصفحة يقوم بتنزيل ملف الـ PDF الخاص بك `CV.pdf`.
10. **تجاوب كامل 100%**: متوافق مع الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة.

## 🚀 كيفية رفع الموقع على GitHub Pages (خطوة بخطوة)

لديك خياران لرفع الموقع على GitHub ليصبح متاحاً للجميع برابط مجاني:

### الخيار الأول (الأسهل والأكثر شيوعاً): رفع المشروع في مستودع باسم `portfolio`
سيكون رابط موقعك:  
`https://<username>.github.io/portfolio`

1. افتح حسابك على [GitHub](https://github.com) وأنشئ مستودعاً جديداً (**New Repository**) باسم `portfolio`.
2. اجعل المستودع **Public**.
3. افتح التيرمينال في مجلد هذا المشروع ونفذ الأوامر التالية (استبدل `<your-username>` باسم مستخدم حسابك على GitHub):

```bash
cd /home/eng-yousef/.gemini/antigravity/scratch/yousef-portfolio

# تهيئة مستودع Git
git init
git add .
git commit -m "Initial commit: Yousef Hosny Data Engineer Portfolio"

# تغيير اسم الفرع إلى main
git branch -M main

# ربط المستودع بحسابك على GitHub
git remote add origin https://github.com/<your-username>/portfolio.git

# رفع الملفات
git push -u origin main
```

4. **تفعيل GitHub Pages من الإعدادات:**
   - ادخل على المستودع على موقع GitHub.
   - اذهب إلى **Settings** ➔ من القائمة الجانبية اختر **Pages**.
   - تحت قسم **Build and deployment** ➔ **Source**: اختر **Deploy from a branch**.
   - تحت **Branch**: اختر `main` واضغط **Save**.
   - خلال دقيقة أو دقيقتين ستظهر رسالة خضراء برابط موقعك الحي:
     `https://<your-username>.github.io/portfolio`

### الخيار الثاني: جعله موقع حسابك الرئيسي (Username Site)
سيكون رابط موقعك:  
`https://<your-username>.github.io`

1. أنشئ مستودعاً على GitHub بالاسم التالي تماماً:  
   `<your-username>.github.io`  
   *(مثال: إذا كان اسم حسابك `yousef-hosny`، يكون اسم المستودع `yousef-hosny.github.io`)*.
2. ارفع الملفات إليه بنفس الطريقة:
```bash
cd /home/eng-yousef/.gemini/antigravity/scratch/yousef-portfolio
git init
git add .
git commit -m "Launch Yousef Hosny Portfolio"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
git push -u origin main
```
3. سيعمل الموقع تلقائياً على الرابط المباشر `https://<your-username>.github.io` خلال ثوانٍ معدودة.
